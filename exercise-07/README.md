# Exercise 07: Develop a Menu on a Branch

## Objective
Create a feature branch `feature/menu`, develop `menu.sh` with four distinct operations (Greet, Add Integers, Even/Odd Check, Exit), test each option, commit changes on the branch, and merge into `main`.

## Operations Implemented
1. **Greet User**: Validates user name input and displays welcome banner.
2. **Add Two Integers**: Performs integer addition with regex input validation.
3. **Check Even or Odd**: Computes modulo arithmetic to report parity.
4. **Exit**: Exits cleanly with status code 0.
