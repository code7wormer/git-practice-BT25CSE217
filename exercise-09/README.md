# Exercise 09: Resolve a Merge Conflict

## Objective
Create a controlled merge conflict by modifying the same line in `mode.txt` on both `main` (`Lab mode: classroom`) and `feature/mode` (`Lab mode: online`). Attempt merge, inspect standard conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`), resolve to agreed text (`Lab mode: hybrid`), stage, and record a merge commit.

## Conflict Analysis
- **Current branch (`HEAD` / `main`):** `Lab mode: classroom`
- **Incoming branch (`feature/mode`):** `Lab mode: online`
- **Resolution (`mode.txt`):** `Lab mode: hybrid`
