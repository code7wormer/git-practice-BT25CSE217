# Exercise 04: Stage Selected Files

## Objective
Demonstrate selective staging by creating two files, staging and committing only one while ensuring the second remains untracked in the working directory, inspecting `git status` before and after, and finally committing the second file.

## Files Created
- `file_alpha.txt`: Staged and committed first.
- `file_beta.txt`: Remained untracked during the first commit, committed subsequently.
