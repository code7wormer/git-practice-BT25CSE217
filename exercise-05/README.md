# Exercise 05: Inspect Staged and Unstaged Edits

## Objective
Understand Git's two-step recording model (Working Tree $\rightarrow$ Index / Staging $\rightarrow$ Commit / HEAD) by creating both staged and unstaged edits in `README.md`, observing status `MM`, and comparing diffs using:
1. `git diff` (Working Tree vs Index)
2. `git diff --staged` (Index vs HEAD)
3. `git diff HEAD` (Working Tree vs HEAD)
