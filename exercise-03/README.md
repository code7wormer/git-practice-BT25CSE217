# Exercise 03: Write and Improve a Greeting Script

## Objective
1. Write a shell script `greet.sh` that prompts for a user name and outputs a greeting message.
2. Record an initial commit.
3. Enhance the script to handle empty inputs gracefully with an error message and non-zero exit code.
4. Record the enhancement in a separate descriptive commit.
